## 📌 Overview

This is my dedicated repository for **WIPRO's Pre-Placement Python Automation
Training Program (CoE)**, tracking my complete journey from Selenium
fundamentals to a production-style, multi-framework test automation portfolio.

It contains three things:

- 📚 **Daily course work and lab assignments** — every topic covered during
  the course, implemented and (where applicable) explained on video
- 🛒 **A hands-on capstone project** — a production-style E-Commerce
  automation framework built with Selenium, Python, and Pytest
- 🎓 **Certifications** — three completed Coursera courses that structured
  this learning path, from Selenium basics through Playwright and Robot
  Framework

## 🛒 Capstone Project — E-Commerce Automation Framework

A production-style Selenium + Python + Pytest framework automating a
complete e-commerce testing journey on the TutorialsNinja demo store —
login, product search, cart operations, and logout — built with the Page
Object Model, data-driven testing via CSV, automatic failure screenshots,
and self-contained HTML reporting.

## 🧰 Tech Stack (Across the Repository)

| Technology | Used For |
|:---|:---|
| 🐍 **Python 3.10** | Core language across every script and framework |
| 🌐 **Selenium WebDriver 4.x** | Browser automation |
| 🚗 **webdriver-manager** | Automatic driver version management |
| 🧪 **Pytest** | Fixtures, assertions, test execution |
| 📊 **pytest-html** | Self-contained HTML reports with embedded failure screenshots |
| 🥒 **Behave** | BDD automation using Gherkin syntax |
| 🤖 **Robot Framework** | Keyword-driven test automation |
| 🧱 **Page Object Model** | Maintainable automation architecture |
| 📄 **pandas / CSV** | Data-driven test inputs |
